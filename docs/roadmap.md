# Plumbing Enquiry Engine — Roadmap

## Phase 1 — Complete
- Working V1 prototype.
- Commercial workflow demonstrated.
- GitHub repository established.
- Product tracker established.
- Outreach, feedback and action tracking established.
- Product documentation established.

## Phase 2 — Validate
- Demonstrate the prototype to real plumbing businesses.
- Record objections, questions and requested improvements.
- Identify the highest-value workflow problem.
- Secure a pilot/customer.

## Phase 3 — Build
Only after validation:
- Connect to real enquiry sources.
- Add business-specific qualification rules.
- Add routing and prioritisation.
- Add response/quote preparation.
- Add follow-up automation.
- Integrate with the customer's existing systems where appropriate.

## Phase 4 — Productise
- Create a reusable service-business version.
- Adapt the engine for HVAC, electrical, building, cleaning and similar businesses.
- Establish repeatable implementation and pricing.

## Rule
No feature is added simply because it is technically possible.
Commercial evidence comes first.
